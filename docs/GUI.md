# DiskDownloader

Сохраняет выбранные папки вашего Яндекс Диска вместе со всеми подпапками. Повторный запуск находит новые файлы и продолжает прерванные загрузки.

## Запуск

Распакуйте архив целиком и откройте файл своей системы двойным щелчком:

| Система | Файл запуска |
| --- | --- |
| macOS | `run-gui.command` |
| Windows | `run-gui.bat` |

Если подходящий Python уже есть, приложение откроется сразу. Иначе программа предложит установить Python с поддержкой оконного интерфейса: **Y** — согласиться, **Enter** или **N** — отменить.

Для установки нужен интернет. На **Windows** Python устанавливается для текущего пользователя без прав администратора. На **macOS** потребуется пароль администратора в системном окне; поддерживаются Intel и Apple Silicon с macOS 10.15 или новее. Установщик загружается с python.org и проверяется перед запуском. На Mac также загружается пакет сертификатов HTTPS из PyPI.

После установки приложение запустится автоматически. Если существующая установка Python повреждена, программа покажет инструкцию по её восстановлению.

## Подключение к Диску

1. Нажмите **«Получить токен»** или откройте [страницу получения токена](https://oauth.yandex.ru/authorize?response_type=token&client_id=98979c5296c34f9faea9ab76847efb68) вручную. В браузере откроется страница Яндекса.
2. Войдите в нужный аккаунт, нажмите **«Разрешить»** и скопируйте выданный OAuth-токен.
3. Вставьте токен в скрытое поле приложения: **Cmd+V** на Mac или **Ctrl+V** на Windows. Нажмите **«Подключиться»**.

Доступ через встроенную ссылку зависит от настроек OAuth-приложения. Если Яндекс не разрешает получить токен вашему аккаунту, используйте собственное приложение с правом **`cloud_api:disk.read`** и вставьте его токен в то же поле. У приложений типа «Для доступа к API» доступ ограничен данными разработчика: [типы приложений](https://www.yandex.ru/dev/id/doc/ru/register-client), [регистрация](https://yandex.com/dev/id/doc/ru/register-api).

При подключении или запуске копирования токен сохраняется автоматически: в **Связке ключей macOS** или **Диспетчере учётных данных Windows**. При следующем запуске он подставляется в поле. Если система запросит доступ к хранилищу, разрешите его. Токен не записывается в настройки или журнал.

Кнопка **«Удалить»** очищает поле и сохранённый токен. Она не отзывает разрешение в аккаунте Яндекса.

## Выбор папок

1. Укажите общую папку на компьютере для новых заданий. Можно выбрать внешний диск.
2. В дереве Яндекс Диска выделите нужные папки и нажмите **«Добавить выбранные»**. Несколько папок выделяются с Cmd/Ctrl; диапазон — с Shift. Известный путь можно добавить кнопкой **«Добавить по пути»**.
3. Для каждого источника выберите отдельную локальную папку. Назначение меняется кнопкой **«Куда сохранить»**. В неё сохраняется содержимое исходной папки со всей структурой.
4. Нажмите **«Начать копирование»**.

Очередь и настройки сохраняются автоматически. Строку можно временно выключить кнопкой **«Вкл. / выкл.»**. Удаление строки из очереди оставляет скачанные файлы на компьютере.

## Копирование и повторные запуски

- **`[ЕСТЬ]`** — готовый неизменившийся файл пропущен. Повторно он не скачивается.
- Отсутствующие файлы скачиваются, частичные — докачиваются, если сервер это позволяет.
- Изменившийся оригинал заменяет прежнюю копию только после полной загрузки и проверки. При ошибке прежняя копия остаётся на месте.
- Ошибка одного файла не останавливает обработку остальных. Файлы, исчезнувшие на Диске, остаются в локальной копии.

Рядом с **«Ход копирования»** показано число успешно сохранённых оригиналов за этот запуск, включая обновлённые. Уже готовые файлы и частичные загрузки в счётчик не входят.

Параметр **«Потоков»** задаёт число одновременных загрузок. **«Таймаут»** — время ожидания сетевого ответа, а **«Повторов»** — число дополнительных попыток после ошибки. Например, при таймауте 60 секунд в журнале может не быть новых строк, пока сервер не ответит.

Галочка **«Сверять SHA-256»** дополнительно проверяет содержимое уже сохранённых файлов. Это занимает время; без неё программа сравнивает сохранённые сведения о версии и локальном файле.

## Проходить по кругу

Включите **«Проходить по кругу»**, чтобы после обхода всех включённых папок программа начинала новый круг. Между кругами выдерживается указанная пауза, по умолчанию 60 секунд. Каждый круг снова пробует недоступные оригиналы и находит появившиеся файлы.

Повторение продолжается до нажатия **«Остановить»**. Остановка сохраняет готовые файлы и частичные загрузки, а также прерывает ожидание между кругами. Для изменения параметров остановите копирование.

## Превью недоступных оригиналов

Галочка **«Сохранять превью при ошибке оригинала»** включает загрузку изображения предпросмотра, если все попытки скачать оригинал завершились ошибкой. Превью доступно не для каждого файла, даже если изображение видно в браузере.

Превью сохраняется **под именем и по пути оригинала**. Его фактический формат может отличаться от расширения: например, файл `.heic` может временно содержать изображение JPEG. Если на месте уже есть прежняя полная копия, уменьшенное превью её не перезаписывает.

Программа помечает превью в своём учёте и считает отдельно в строке **«Превью»**. Ошибка оригинала остаётся в отчёте. Каждый следующий круг или запуск снова пытается скачать оригинал, **даже при выключенной проверке SHA-256**. Когда оригинал доступен, программа скачивает и проверяет его, затем атомарно заменяет превью. До успешной замены изображение остаётся на месте.

## Настройки, обновление и перенос

Список папок и параметры находятся в `download-gui.json` рядом с программой. В каждой папке назначения есть скрытая служебная папка **`.disk-downloader`** с прогрессом, отметками превью и частичными загрузками. **Сохраняйте её вместе со скачанными файлами.**

При обновлении заменяйте файлы приложения, сохраняя настройки, папки копий и установленный Python, включая `.venv`, если она используется. Чтобы сохранённый токен подставлялся как раньше, оставьте папку программы на прежнем месте. После переноса программы в другую папку или на другой компьютер может потребоваться повторная вставка прежнего токена.

Для продолжения копирования с Mac на Windows:

1. Остановите копирование. Перенесите папки назначения целиком, **включая `.disk-downloader`**.
2. Распакуйте Windows-версию отдельно, без файлов `download-gui.json` и `download.json` с Mac: сохранённые пути `/Users/...` и `/Volumes/...` не подходят для Windows. Заново добавьте те же папки Яндекс Диска и выберите их перенесённые локальные назначения, например `E:\DiskBackup\Фото`.
3. Вставьте **тот же OAuth-токен**. Токен из системного хранилища Mac автоматически не переносится. Другой токен требует новой папки назначения, поскольку учёт источника связан с токеном и путём на Диске.

Программа может сохранить только данные, которые Яндекс Диск сейчас перечисляет и отдаёт. Если другие файлы станут доступны позже, следующий круг или запуск попробует их скачать.
